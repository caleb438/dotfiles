# tmux

My personal tmux configuration.

## Structure

tmux.conf
    Entry point.

options.conf
    General behavior.

keybinds.conf
    Keyboard shortcuts.

status.conf
    Status bar layout.

## Installation

Clone the repository and symlink the directory to:

~/.config/tmux

## Useful Shortcuts

Prefix + r
    Reload configuration.

Prefix + |
    Vertical split.

Prefix + -
    Horizontal split.

Prefix + c
    New window in current directory.

Prefix + (
    Previous session.

Prefix + )
    Next session.
